3. Основные понятия

  • Персональные данные — любая информация, относящаяся к прямо или косвенно определённому физическому лицу.
  • Обработка персональных данных — любое действие с персональными данными: сбор, запись, систематизация, хранение, уточнение, использование, передача, удаление, уничтожение.
  • Оператор — лицо, организующее и осуществляющее обработку персональных данных, а также определяющее цели и состав обрабатываемых данных.
  • Пользователь — посетитель Сайта.
  • Обезличивание — действия, в результате которых невозможно определить принадлежность данных конкретному пользователю.

4. Какие данные мы обрабатываем

Оператор обрабатывает только те данные, которые пользователь предоставляет добровольно, заполняя формы на Сайте:

  • имя (или то, как пользователь представился);
  • номер телефона;
  • адрес электронной почты — если пользователь указал его при обращении;
  • город и вид услуги, выбранные в форме;
  • описание неисправности, которое пользователь ввёл самостоятельно;
  • адрес выезда мастера — сообщается устно при согласовании заявки и используется только для оказания услуги.

Кроме того, автоматически собираются обезличенные технические данные: IP-адрес, тип и версия браузера, операционная система, источник перехода, просмотренные страницы, время визита. Эти данные собираются средствами систем аналитики (см. раздел 7) и не позволяют идентифицировать пользователя.

Оператор не обрабатывает специальные категории персональных данных (раса, национальность, политические и религиозные убеждения, состояние здоровья, интимная жизнь) и биометрические персональные данные.

Сайт не предназначен для лиц младше 18 лет. Оператор не собирает осознанно данные несовершеннолетних.

5. Цели обработки

Персональные данные обрабатываются исключительно для:

  • обратной связи по оставленной заявке — уточнения деталей, согласования времени и адреса выезда мастера;
  • оказания услуг по ремонту и обслуживанию техники;
  • оформления документов по выполненным работам, включая гарантийные обязательства;
  • рассмотрения обращений, претензий и гарантийных случаев;
  • улучшения работы Сайта на основании обезличенной статистики.
Оператор не использует контактные данные для рассылок рекламного характера и не передаёт их третьим лицам в маркетинговых целях.

6. Правовые основания обработки

Оператор обрабатывает персональные данные на следующих основаниях:

  • согласие пользователя на обработку персональных данных, выраженное проставлением отметки в соответствующем поле формы на Сайте;
  • исполнение договора, стороной которого является пользователь (оказание услуг по ремонту);
  • исполнение обязанностей, возложенных на Оператора законодательством Российской Федерации.

7. Файлы cookie и системы аналитики

Сайт использует файлы cookie — небольшие текстовые файлы, сохраняемые браузером. Они нужны для корректной работы страниц и для сбора обезличенной статистики посещаемости.

Для анализа посещаемости используется сервис Яндекс.Метрика (ООО «ЯНДЕКС»). Сервис собирает обезличенные данные о поведении пользователей на Сайте. Условия обработки данных описаны в документах сервиса; отказаться от сбора можно, установив блокировщик Яндекс.Метрики.

Пользователь может запретить сохранение cookie в настройках браузера. Это не помешает просмотру Сайта, но часть функций может работать некорректно.

8. Передача данных третьим лицам

Оператор не продаёт и не передаёт персональные данные третьим лицам, за исключением случаев, прямо описанных ниже:

  • передача мастеру, выезжающему по заявке, — в объёме, необходимом для оказания услуги;
  • передача по требованию уполномоченных государственных органов в порядке, установленном законодательством РФ.
